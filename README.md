## 📖 Introducción

La **Programación Orientada a Objetos (POO)** es un paradigma de programación que organiza el desarrollo de software a partir de **objetos**, los cuales representan entidades del mundo real y contienen tanto datos como comportamientos. Este enfoque permite estructurar los programas de manera más clara, modular y reutilizable, facilitando el mantenimiento y la escalabilidad del código.

En lugar de centrarse únicamente en funciones y procedimientos, la POO se basa en la creación de **clases**, que actúan como plantillas para generar objetos. Cada objeto puede tener **atributos** (propiedades o características) y **métodos** (acciones o comportamientos), lo que permite modelar problemas de manera más natural y cercana a la realidad.

La programación orientada a objetos se apoya en principios fundamentales como el **encapsulamiento**, la **herencia**, el **polimorfismo** y la **abstracción**, los cuales ayudan a mejorar la organización del código y promueven la reutilización de componentes dentro de un sistema.

Actualmente, la POO es uno de los paradigmas más utilizados en el desarrollo de software moderno y es la base de muchos lenguajes de programación populares como **Java, Python, C++, C# y JavaScript**. Gracias a sus ventajas, es ampliamente utilizada en el desarrollo de aplicaciones web, sistemas empresariales, videojuegos y software en general.

Comprender los fundamentos de la programación orientada a objetos es esencial para cualquier desarrollador, ya que permite diseñar soluciones más eficientes, estructuradas y adaptables a distintos tipos de problemas en el ámbito de la ingeniería de software.
