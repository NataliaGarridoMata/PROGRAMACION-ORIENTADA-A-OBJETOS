🐶🐱 Sistema de Animales en Python - Programación Orientada a Objetos
📌 Descripción

Este proyecto implementa un pequeño sistema de animales utilizando Programación Orientada a Objetos (POO) en Python.

Se trabaja con una clase padre llamada Animal y dos clases hijas (Perro y Gato) que heredan atributos y métodos,
aplicando el concepto de herencia y polimorfismo.

El programa permite crear animales y hacer que cada uno “hable” de manera diferente según su tipo.
