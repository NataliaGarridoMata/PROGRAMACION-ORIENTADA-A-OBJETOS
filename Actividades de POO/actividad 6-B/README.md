# 🛠️ Sistema de Herramientas en Python

# Natalia Yamile Garrido Mata 

🎯 Objetivo del Proyecto

El objetivo principal es practicar la creación de sistemas orientados a objetos utilizando clases abstractas y herencia en Python,
simulando herramientas con comportamientos específicos.

Este proyecto implementa un sistema básico de herramientas inspirado en videojuegos como Minecraft,
utilizando los principios de la **Programación Orientada a Objetos (POO)** en Python.

El programa permite crear diferentes herramientas con materiales específicos, calcular su daño, 
controlar su durabilidad y simular el uso de cada una.

Este proyecto utiliza varios conceptos importantes de POO:

- Clases y objetos
- Herencia
- Polimorfismo
- Encapsulamiento
- Clases abstractas
- Métodos abstractos
- Propiedades (`@property`)
- Modularización de archivos
