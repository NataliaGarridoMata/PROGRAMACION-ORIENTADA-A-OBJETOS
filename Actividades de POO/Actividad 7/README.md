El manejo de excepciones es una herramienta fundamental en Python que permite controlar errores durante la ejecución de un programa sin que este se detenga inesperadamente.

Una excepción es un error que ocurre en tiempo de ejecución y que interrumpe el flujo normal del programa. Python nos permite detectar y manejar esos errores utilizando bloques especiales como `try` y `except`.

---

# 📚 ¿Qué es una excepción?

Una excepción ocurre cuando el programa encuentra una situación que no puede resolver automáticamente.

### Ejemplos comunes:
- Dividir entre cero
- Abrir un archivo inexistente
- Convertir texto a número incorrectamente
- Acceder a índices inexistentes

Si no se manejan, el programa termina mostrando un mensaje de error.
