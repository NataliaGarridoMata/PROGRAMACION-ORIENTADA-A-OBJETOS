📌 Descripción del Proyecto

Este proyecto implementa un simulador de mobs de Minecraft utilizando Programación Orientada a Objetos (POO) en Python.

Se emplea una clase abstracta llamada Mob, la cual define la estructura general que deben seguir todos los mobs del juego.
Las clases concretas como Vaca, Creeper, Enderman y Zombie heredan de esta clase y proporcionan su propio comportamiento.

El objetivo es practicar conceptos avanzados de POO como:

Clases abstractas
Métodos abstractos
Herencia
Polimorfismo
Sobrescritura de métodos
Organización modular del código
