##  👩‍🎓 Natalia Yamile Garrido Mata 

# 📌 DESCRIPCION 
Este proyecto implementa un pequeño sistema de personajes utilizando Programación Orientada a Objetos (POO) en Python.

Se trabaja con una clase padre llamada Aventurero, y con 4 clase hija (Arquero,Guerrero,Mago y Elfo),
que heredan atributos y métodos, aplicando el concepto de herencia y polimorfismo.

El programa nos permite que el usuario conviva con los distintos personajes, los conozca y sepa cuales son sus 
metodos de defenza, para que asi el usuario pueda aumentar el poder de cada personaje.
