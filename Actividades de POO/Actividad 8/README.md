# Sistema de Jugadores
Natalia Yamile Garrido Mata 

Este proyecto en Python representa un sistema básico de jugadores utilizando Programación Orientada a Objetos (POO).  
Incluye diferentes tipos de usuarios como jugadores, competidores y observadores.

## 📂 Estructura del Proyecto

- `Jugador.py` → Clase base para los jugadores.
- `Competidor.py` → Clase derivada para competidores.
- `Observador.py` → Clase derivada para observadores.
- `main.py` → Archivo principal para ejecutar el programa.

---

## 🚀 Funcionalidades

La clase `Jugador` permite:

- Crear jugadores con:
  - Nombre
  - Número de control
  - Nivel
  - Puntos

- Ganar puntos.
- Perder puntos.
- Mostrar perfil del jugador.
