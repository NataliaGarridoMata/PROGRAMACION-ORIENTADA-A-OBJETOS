# 🍪☕🥗 SISTEMA DE RESTAURANTE EN PYTHON 
## 👩‍🎓 Natalia Yamile Garrido Mata 

# 📌 DESCRIPCION
Este proyecto implementa un pequeño sistema de platillos utilizando
Programación Orientada a Objetos (POO) en Python.

Se trabaja con unaz clase Padre llamada Platillo, que cuenta con 3 clases hijas,
que son (Bebida,Comida y Postre), que heredan atributos y métodos, aplicando el concepto de herencia y polimorfismo.

Es un programa que permite al cliente conocer el menú del dia, el precio y la categoria del alimento, para que el 
consumidor espere con mas confianza sus alimentos
