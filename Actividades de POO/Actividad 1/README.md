📘 Proyecto: Clase Estudiante en Python
📖 Descripción General

Este proyecto contiene una implementación básica de Programación Orientada a Objetos (POO) en Python, enfocada en la creación y uso de
una clase llamada Estudiante. Además, se incluye un diagrama (archivo .drawio) que representa visualmente la estructura de la clase.

El objetivo principal es demostrar conceptos fundamentales como atributos, métodos, encapsulamiento y manipulación de objetos.

🎯 Objetivo del Proyecto

El proyecto tiene como finalidad reforzar los conceptos básicos de la Programación Orientada a Objetos mediante un ejemplo sencillo y práctico, 
permitiendo entender cómo se modelan entidades del mundo real en código.
